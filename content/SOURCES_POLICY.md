# Criterio de evidencia de Tutor Rodach

Tutor Rodach no debe mostrar textos como «fuentes confiables» sin identificar una referencia concreta.

Antes de publicar una fuente deben estar comprobados:

- autor o autores;
- título exacto;
- año;
- revista, libro, editorial o institución;
- DOI o enlace oficial verificable;
- afirmación concreta que la fuente respalda;
- límites de lo que la fuente permite afirmar.

Si un comentario no tiene una fuente comprobada, se mostrará como **orientación de práctica de Rodach**, no como resultado científico. Nunca se inventarán universidades, estudios, fechas o autores.

El archivo `content/verified-sources.json` contiene únicamente referencias que ya tienen datos bibliográficos concretos. Las demás fuentes se incorporarán después de comprobarlas.
