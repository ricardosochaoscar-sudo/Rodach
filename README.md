# Proyecto de Oratoria

Página web educativa sobre oratoria dirigida a estudiantes de 12 a 16 años.

El proyecto busca enseñar de manera dinámica y práctica cómo mejorar la expresión oral, la comunicación, la confianza al hablar en público, la argumentación y el lenguaje corporal mediante videos, ejercicios y contenido interactivo.
